# Sistema_NPJ_LTD

Sistema web em desenvolvimento para auxiliar o gerenciamento do Núcleo de Prática Jurídica (NPJ).

## 🚧 Status do projeto

Projeto atualmente em desenvolvimento.

## 🚀 Sobre o sistema

O sistema foi desenvolvido para auxiliar na organização e gerenciamento das atividades do NPJ, permitindo o cadastro e gerenciamento de assistidos, controle de informações e suporte às atividades administrativas.

## 🛠 Tecnologias utilizadas

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
